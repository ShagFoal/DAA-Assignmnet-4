## Как начать

1. Нажмите **Use this template → Create a new repository**, создайте свой репозиторий и клонируйте его на компьютер. Работайте в своей копии.
2. Прочитайте полное задание и CONTRACTS.md. В `submission.json` выберите `Java`, `Python`, `Cpp` или `CSharp`. Для launcher нужен Python 3.12+, для решения — выбранный runtime: JDK 17+, Python 3.12+, C++17 или .NET 8.
3. Из корня выполните `python tools/run.py --setup`: это проверка запуска, а не готовности алгоритмов.
4. Реализуйте TODO-методы в папке `source` выбранного языка. Сохраните JSON Lines интерфейс. Добавьте собственные тесты в `tests/student` и заполните `ANALYSIS.md` на английском.
5. Выполните `python tools/run.py --check`, проверьте границы и полный диапазон входов. Сделайте commit и push; проверьте **Actions → Public checks** для этого коммита. В официальном шаблоне проверяется запуск четырёх языков, в вашей копии — также результаты алгоритмов.

## Что сдать

В [Moodle → Assignment 4](https://lms.astanait.edu.kz/mod/assign/view.php?id=95272) вставьте **ссылку точного коммита с полным SHA из 40 символов** и выбранный язык. Ссылку Actions для того же коммита можно приложить дополнительно. При приватном репозитории дайте преподавателю доступ. Нажмите **Submit assignment** и проверьте итоговый статус. До дедлайна можно обновить работу и заменить ссылку. ZIP вместо ссылки не сдаётся.

В коммите должны быть исходники, `submission.json`, собственные тесты, заполненный английский `ANALYSIS.md` и реальные команды запуска/проверки. Объясните корректность, восстановление, сложность и воспроизводимое сравнение naive/KMP/exact RK. Укажите использованные источники и ИИ, их вклад и вашу проверку.

На [сайте](https://rzhaniya.github.io/daa-assignment-4-archive/) доступны двуязычный урок, восемь интерактивных моделей и отдельная открытая тренировка: **15 вопросов / 25 минут**. Исходники сайта находятся в `docs/`; публикация — GitHub Pages. Учебные вопросы отличаются от оцениваемой защиты.

[Защита в Moodle](https://lms.astanait.edu.kz/mod/quiz/view.php?id=95271): 15 вопросов за 25 минут, одна попытка, английский; 10 вопросов с одним ответом и 5 с несколькими верными вариантами, три страницы по пять. Правила частичного балла приведены в Moodle.

Практика — 19 групп на 50 баллов; защита — 50. A4 даёт 20% второй аттестации; Quiz II отдельно. Public checks не выставляют официальную оценку. [Рубрика](RUBRIC.md), [тестирование](TESTING.md), [сдача](SUBMISSION.md).
